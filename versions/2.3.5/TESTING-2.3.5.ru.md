# Проверка версии 2.3.5

Java 21 / Minecraft 1.21.1 / NeoForge 21.1.256: сборка и 49 модульных тестов прошли. Выделенный сервер без дополнительных модов — 20 проверок; настоящий клиент с полным набором модов — 47; отдельный процесс после выхода из игры — 8; отдельный клиент без дополнительных модов и библиотек анимации — 47. Все проверки прошли.

Анимации sit1 и stand импортированы из пользовательского model.bbmodel. Числовые ключи и их время сохранены точно. Ключи заканчиваются на 1,0 секунде, а дорожки имеют длину 1,4 секунды: последние 0,4 секунды удерживается поза. Linear и Catmull-Rom воспроизводятся численно. Дополнительные модульные тесты проверяют авторские ключи, удержание, совпадение конца sit1 с началом stand, плавность между ключами и отсутствие скачка при раннем выходе и повторном открытии.

В нативном RenderLivingEvent.Post проверены реальные повороты и смещения модели после применения ключей, а также совпадение используемой текстуры со скином игрока. В JAR нет anima.png и встроенной текстуры из проекта; используется штатный PlayerRenderer с автоматическим выбором Steve/Alex, вторым слоем скина и штатными слоями экипировки. Исходный bbmodel сохранён только в архиве исходников. Размеры и UV игрока берутся из самой игры.

ПКМ запускает посадку. При кнопке «Выйти» и настоящем Esc доступ закрывается сразу, сервер сохраняет носитель на время stand, затем освобождает игрока. Камера входит и возвращается за 1,4 секунды; в журнале записаны настоящие промежуточные кадры. Проверены вложенные окна, ранний выход, повторный вход во время вставания, первая и зеркальная третья перспектива, движение и телепортация во время возврата, настоящий переход в Нижний мир из сидячего положения и обратный путь.

Игра полностью закрыта во время сидения, затем запущена новым процессом. Игрок появляется стоя на сохранённой безопасной позиции; временные сущности не сохраняются, повторная посадка и вставание работают. Выделенный сервер также повторяет авторизацию, личные точки, сохранения, удаление опоры и границы ауры маны. Тестовый транспорт сервера использует настоящий ServerPlayer с отключённой отправкой пакетов; штатный FakePlayer запрещает startRiding.
