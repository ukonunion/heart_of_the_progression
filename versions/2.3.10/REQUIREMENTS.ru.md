# Требования к использованию в 2.3.10

Строка «Требуется:» появляется в подсказке сразу под названием предмета. Она содержит только те атрибуты, которых пока не хватает. Порог проверяется включительно: при Выносливости 15 железная кирка уже доступна, строка исчезает. При нескольких требованиях достаточно выполнить одно, чтобы убрать именно его из списка. До выполнения остальных предмет остаётся недоступен.

Стандартные требования: железные инструменты и оружие — Выносливость 15, алмазные — 20, незеритовые — 25. Проверяется материал TieredItem, включая оружие Epic Fight со стандартным материалом. У деревянных, каменных и золотых предметов стандартного требования нет. Другим предметам дополнительные условия не назначаются автоматически. Броня не получает требования Выносливости от этого правила.

Зельеварка и чародейский стол требуют Интеллект 15. Проверка действует и для предмета, и для уже размещённого блока, в том числе при клике пустой рукой. Нельзя обойти проверку подменой клиентского экрана. Если открывшему интерфейс игроку снизить интеллект ниже 15, сервер закроет этот интерфейс. Клик с зажатым Shift для установки другого разрешённого предмета рядом с блоком не считается открытием его меню. Автоматическое варение без участия игрока этим правилом не останавливается. Творческий режим и наблюдатель сохраняют прежнее исключение из запретов использования.

## Дополнительные условия

В серверном rpgprogression-server.toml раздел itemRequirements содержит отдельные списки strength, endurance, agility, vitality, intelligence и spark_potential. Примеры:

```toml
[itemRequirements]
strength = ["minecraft:diamond_sword=15"]
endurance = []
agility = []
vitality = []
intelligence = []
spark_potential = []
```

Алмазный меч из примера требует Силу 15 и стандартную Выносливость 20. При достижении Выносливости 20 останется только строка Силы, после Силы 15 исчезнет вся строка.

Точное правило для предмета заменяет стандартный порог соответствующего атрибута. Например, endurance = ["minecraft:diamond_sword=30"] меняет Выносливость этого меча на 30, а запись minecraft:diamond_sword=0 отключает его стандартное требование Выносливости. Пользовательские правила тегов вида #minecraft:swords=15 также поддерживаются; среди нескольких совпавших пользовательских правил используется наибольший порог. Пустой список сохраняет стандартные правила материала и двух рабочих блоков.

## Рецепты

Требования использования и доступ к созданию по рецепту — отдельные правила. Прежние пороги рецептов по интеллекту сохранены, кроме согласования чародейского стола с Интеллектом 15. Открытие рецептов больше не создаёт сообщения в чате и рецептные всплывающие уведомления. Книга рецептов продолжает получать разрешённые рецепты; другие типы уведомлений работают.
