# Текстуры Heart of the Progression 0.5.0

Все 16 PNG скопированы из предоставленных изображений без изменения пикселей. Путь ресурсов: `src/main/resources/assets/rpgprogression/textures/`.

## Меню

| Файл в `gui/` | Размер | Назначение |
|---|---|---|
| `menu_main.png` | 640×360 | Весь фон меню, рамки, значки, разделители |
| `button_on.png` | 9×9 | Можно потратить очко |
| `button_off.png` | 9×9 | Очков недостаточно или достигнут максимум |

Образец пользователя сохранён в `docs/reference/menu-example.png`; он не используется как текстура интерфейса. Имя игрока, модель, цифры и надписи рисуются динамически. В меню здоровье, стамина, резервуар искры и необязательная мана отображаются числами. Дополнительные статические PNG прежних меню не нужны.

| `hp/survival/poison.png` | 80×9 | Отравление |
| `hp/survival/wither.png` | 80×9 | Иссушение |
| `hp/survival/frozen.png` | 80×9 | Полное замерзание |
| `hp/hardcore/main_hc.png` | 80×9 | Обычное здоровье в хардкоре |
| `hp/hardcore/absorption_hc.png` | 80×9 | Поглощение в хардкоре |
| `hp/hardcore/poison_hc.png` | 80×9 | Отравление в хардкоре |
| `hp/hardcore/wither_hc.png` | 80×9 | Иссушение в хардкоре |
| `hp/hardcore/frozen_hc.png` | 80×9 | Полное замерзание в хардкоре |
| `hunger/hunger.png` | 80×10 | Обычный голод |
| `hunger/hunger_effect.png` | 80×10 | Только при эффекте «Голод» |
| `stamina/base_stamina.png` | 80×10 | Общая стамина RPG, включая совместимые моды |

Одновременно рисуется ровно один вариант HP и один вариант голода. Если эффекты здоровья совпали, приоритет: иссушение → отравление → замерзание → поглощение → обычное. После окончания эффекта выбирается следующий действующий вариант. Поглощение включено в единственную шкалу здоровья: `(HP + поглощение) / (максимум HP + максимум поглощения)`.

Каждая рамка имеет ширину 80 пикселей. Заполнение идёт из геометрического центра `x=40` парами пикселей; рабочая ширина — 74. Линии толщиной 2 пикселя находятся на `y=4..5` у HP и `y=5..6` у голода/стамины. Сначала рисуются тёмная дорожка и цвет, затем PNG. Центральный значок, границы и полупрозрачные штрихи остаются поверх линий. Для полного заполнения по 37 пикселей с каждой стороны, для половины — по 19 с учётом округления.

| Вариант | Цвет заполнения |
|---|---|
| Обычное HP | Красный `#D32F30` |
| Поглощение | Золотистый `#F4BB28` |
| Отравление | Зелёный `#309F3B` |
| Иссушение | Розово-фиолетовый `#9E5872` |
| Замерзание | Голубой `#24DDE6` |
| Голод | Оранжевый `#E57E45` |
| Эффект голода | Приглушённый розово-коричневый `#A76461` |
| Стамина | Золотой `#E8B12D` |

Здоровье и еда видны постоянно в survival/adventure. Стамина появляется при расходе, восстановлении или истощении и скрывается при полном запасе. Все три рамки центрируются над хотбаром. Воздух, броня и остальные условные показатели сохраняют правила отображения мода. Шкалы искры, маны, XP и прыжка также заполняются от центра.

## Замена через ресурс-пак

1. Поместите `heart-of-the-progression-textures-0.5.0.zip` в `resourcepacks` и включите его, либо редактируйте распакованную папку с таким же именем.
2. Замените нужный PNG в `assets/rpgprogression/textures/`, сохранив путь, размер и прозрачные прорези для заполнения.
3. Нажмите F3+T в игре после сохранения.

Исходник пользователя `menu main.png` имеет пробел; в ресурсах Minecraft он называется `menu_main.png`. Подписи находятся в `lang/ru_ru.json` и `lang/en_us.json`; их можно переопределить тем же ресурс-паком. Координаты меню: `client/gui/CharacterScreen.java`. Выбор эффекта и его цвет: `client/hud/HealthStyle.java`. Геометрия заполнения и цвета голода/стамины: `client/hud/TexturedMeters.java`; расположение и видимость: `client/hud/CenteredHud.java`. Цвета задаются Java-константами и требуют пересборки, сами PNG заменяются ресурс-паком без пересборки.

Скриншоты всех вариантов из игры сохранены в `docs/screenshots/standalone-v140/` и `docs/screenshots/combined-v140/`.
