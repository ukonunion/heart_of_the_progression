# Проверка версии 2.3.7

Java 21 / Minecraft 1.21.1 / NeoForge 21.1.256: сборка и 54 модульных теста прошли. Настоящий клиент с полным набором модов — 140 проверок; клиент без дополнительных модов — 127; перезапуск отдельным процессом — 8; выделенный сервер без дополнительных модов — 20. Все проверки прошли. Миры HeartSkint236-all/base взяты из предыдущего тестирования 2.3.6; пользовательские сохранения не менялись.

Полная запись перехода в Нижний мир содержит реальные кадры stand, затемнения, смены измерения, загрузки, открытия меню назначения и появления картинки. Затемнение начинается после полной анимации stand 1,4 секунды; его номинальная длительность — 450 мс. На обеих сторонах смены измерения непрозрачность равна 1; у каждого записанного полностью затемнённого кадра проверены чёрные пиксели по сетке через 11 пикселей. Записан ReceivingLevelScreen, полностью закрытый чёрным. При появлении картинки экран — SkintScreen назначения. Промежуточные непрозрачности есть в обе стороны, последний кадр полностью видим. Клиент держит чёрный экран до готовности меню, завершения камеры и компиляции девяти секций у пола рядом с точкой. Во время затемнения Esc не закрывает меню. Событие смены измерения на сервере подтверждает, что игрок уже встал и клиент подтвердил чёрный кадр. Раннее подтверждение до окончания stand не выполняет перенос.

Проверены обратный маршрут между измерениями и маршруты в одном измерении. Esc во время stand отменяет перенос. Удаление точки во время stand и отдельно во время затемнения оставляет игрока у исходного скинта и возвращает его меню без зависшего чёрного экрана. Для проверки сетевого ожидания специально пропущен пакет начала затемнения: сервер не переносит игрока без подтверждения и спустя 10 секунд возвращает рабочее исходное меню и доступ к прокачке. Модульные проверки охватывают плавную монотонную непрозрачность, ожидание долгой загрузки, отмену без скачка и очистку при отключении.

Повторены посадка и авторские ключи, скин игрока, стоящий портрет в характеристиках, дерево, выход кнопкой и Esc, ранний выход и повторный вход, обе перспективы камеры, отсутствие отрисовки тела внутри камеры, движение во время возврата. Финальное положение камеры сравнивается после двух фактически отрисованных кадров после спешивания. Проверены свет скинта 15 и соседний свет 14 ночью, сохранение и повторный запуск без старых носителей. Рецепт действительно появляется в книге, его тост отключён, другой тип уведомления работает. Выделенный сервер повторяет авторизацию, личные открытия, сохранение точек, удаление опоры, ауру маны и отказ для заблокированной цели.

Полный клиент: Epic Fight 21.16.4; ParCool 3.4.3.0; Epic x ParCool 21.0.0; Iron’s 1.21.1-3.16.3; Sodium 0.6.13+mc1.21.1; Iris 1.8.12-snapshot+mc1.21.1-local. Шейдерпак не выбран. Базовый клиент содержит только Minecraft, NeoForge и наш мод. Второй одновременный клиент, сторонние шейдерпаки и полная историческая матрица RPG/GameTests заново не проверялись. Сетевое ожидание проверено пропуском сообщения на настоящем встроенном клиенте; отдельная искусственная задержка сети не применялась.

Примечание о нумерации: полные функциональные прогоны использовали окончательные программные классы 2.3.7, но в метаданных разработки ещё отображался номер 2.3.6. Перед упаковкой исправлен только номер в META-INF/neoforge.mods.toml; классы не менялись и совпадают с проверенными файлами побайтово. После исправления отдельно повторены запуск клиента с полным набором модов и выделенный сервер, оба показывают 2.3.7. Исходные отчёты loadedMods сохранены без изменения.

Проверка JAR: Java 21, версия 2.3.7, отсутствие тестовых классов и вложенных зависимостей, точное соответствие текущим скомпилированным классам. По сравнению с 2.3.6 изменены только 6 существующих классов, добавлены 4; остальные 194 производственных классов совпадают побайтово. Все прежние ресурсы assets/, включая текстуры, локализации, геометрию и анимации, совпадают побайтово. Новые изображения не добавлены. Лицензии сохранены.
