# Проверка 2.3.30

Сборка прошла: 168 модульных тестов без пропусков и ошибок, 32 нативные проверки — по 16 в минимальном клиенте и клиенте с дополнительными модами. Проверочные классы исключены из JAR.

Новые модульные тесты проверяют тихую исходную точку при входе/возрождении/сбросе, монотонный отсчёт по игровым тикам и промежуточным кадрам, точное конечное значение после 12 тиков, продолжение с текущего числа при новой цели, уменьшение до нуля без выхода за границы, соседние целые значения около XP_LIMIT и очень большие long-значения. Имеющиеся тесты таймера, сокращений и остальных механик также прошли.

В настоящем клиенте заранее выпадают две самостоятельные звёздочки по 2477 опыта. После секундной задержки игрок подходит к первой: сервер сразу начисляет 2477, а индикатор проходит через промежуточные числа. Проверены различающиеся значения внутри одного клиентского тика. Затем игрок подходит ко второй до завершения первого отсчёта: сумма становится 4954, а показ продолжает монотонно расти без сброса к нулю и без скачка к новой цели. Итог совпадает с сервером ровно.

Также проверены плавное уменьшение до нуля, отсутствие старой прокрутки после отключения/включения индикатора, автоматическое сокращение итогового большого значения, остановка незавершённого отсчёта настоящим меню паузы, завершение после продолжения игры и полная очистка при сбросе. Подбор выполнен в творческом режиме при creativeGainsXP=false. Настройки механики опыта не менялись.

Клиент с модами: Clavis, OctoLib, Architectury, Epic Fight, ParCool, Epic x ParCool, Iron’s, Relics и библиотеки, Sodium/Iris. Использованы только тестовые миры внутри run проекта. Пользовательские сохранения вне проекта не менялись. Все серверные классы, прочие клиентские классы, конфиги, прежние PNG, переводы и данные побайтово совпадают с 2.3.29. Выделенный сервер и несвязанные полные сценарии повторно не запускались. Протокол остаётся 24. JAR совпадает с текущей компиляцией и загруженными минимальным клиентом производственными классами.
