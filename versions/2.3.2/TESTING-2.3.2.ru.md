# Проверка версии 2.3.2

Java 21 / Minecraft 1.21.1 / NeoForge 21.1.256: сборка и 45 модульных тестов прошли. В настоящем игровом клиенте с текущими модами — 63 проверок без ошибок.

Проверены начало перехода рядом с исходным ракурсом, несколько промежуточных положений, достижение конечного положения за 0,7 секунды, отсутствие обновления снимка во время движения. Приложена последовательность настоящих кадров перехода с временными отметками; GIF воспроизводит эти кадры с паузой в конце для просмотра. Движение камеры идёт по монотонному времени и не зависит от числа игровых тиков.

Проверены раннее закрытие во время анимации, повторный вход, возврат камеры после выхода и телепортации, вход и выход из зеркального вида от третьего лица. Вкладки измерений лишены предметных значков; выбранная текстура, смещение на два пикселя, фильтрация измерений, пустое состояние и реальные кнопки перемещения проверены в игре.

Повторены реальные переходы в Верхнем мире, в Нижний мир и обратно, доступ к характеристикам и дереву только через скинт, расход очка атрибута, отзыв доступа при уходе. Проверены безопасный выход, личные открытия и удвоение восстановления маны в прежнем нативном сценарии. Для проверки использовано тестовое сохранение от 2.3.1.

Моды: Epic Fight 21.16.4; ParCool 3.4.3.0; Epic x ParCool 21.0.0; Iron’s 1.21.1-3.16.3; Sodium 0.6.13+mc1.21.1; Iris 1.8.12-snapshot+mc1.21.1-local. Внешний шейдерпак не выбран.

Все ресурсы, игровые и серверные классы совпадают с 2.3.1. Изменены шесть клиентских классов, включая вложенные: камера, её перехватчик, ожидание снимка, экран перемещения и вкладки. JAR не содержит тестовые сценарии, миры и классы зависимостей. Все классы JAR совпадают с текущими скомпилированными классами.
