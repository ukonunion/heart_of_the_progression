# Проверка 2.3.28

Сборка прошла: 159 модульных тестов без пропусков и ошибок. Пройдена 101 нативная проверка: минимальный клиент — 40, клиент с дополнительными модами — 40, выделенный сервер — 21. Проверочные классы исключены из JAR.

Опыт: сохранены точная ценность и возраст в NBT, лимит 12 звёздочек, слияние, начисление только при подборе, задержка, 16-блочный радиус и медленная скорость, истечение срока и независимость ванильного опыта. Творческий игрок получает полную ценность при creativeGainsXP=false, повторный подбор не начисляет её снова. Проверены настоящие убийства и естественное поглощение клиентом в творческом режиме с серверной синхронизацией; зрители исключены. ProgressionManager и прочие источники XP побайтово совпадают с 2.3.27.

Индикатор: модульно проверены тихая начальная точка, полный пятисекундный интервал, продление при уменьшении и при разнице в одну единицу больших long-чисел, восстановление исходной точки при переподключении/возрождении/отключении. В клиенте показаны целиком 10000 (RU), 1000000 (EN), 9999 после уменьшения и 1234567890123456. Воспользовались настоящей анимацией HudVisibilityAnimation стамины: появление и скрытие по 8 тиков. Проверено исчезновение при неизменном опыте и отсутствие показа только из-за смены языка. Получены скриншоты прямого показа, затухания и скрытого состояния.

Настройки: через зарегистрированную фабрику IConfigScreenFactory открыт штатный экран NeoForge, выбраны Клиентские настройки, найдена локализованная строка «Индикатор RPG-опыта» и нажата её настоящая кнопка. После закрытия showProgressionExperienceHUD=false проверен в сохранённом config/rpgprogression-client.toml. Изменение опыта во время отключения не показывает панель; повторное включение ждёт нового изменения. Отдельно проверены независимость от showStaminaHUD, F1, зритель, два масштаба GUI и очистка анимации.

Клиент с модами: Clavis, OctoLib, Architectury, Epic Fight, ParCool, Epic x ParCool, Iron’s Spells and Spellbooks, Relics и библиотеки, Sodium/Iris. Изолированные миры и конфиги находятся только в run проекта. Пользовательские сохранения за пределами проекта не менялись. Протокол остаётся 24; для творческого подбора обновляются клиент и сервер.

JAR сверен с 2.3.27, текущей компиляцией и загруженными минимальным клиентом классами. Все прежние PNG, ресурсы данных, переводы и несвязанные записи сохранены. Допустимый список изменений указан в VERIFICATION.json. Несвязанные полные сценарии Clavis, требований, дерева навыков, скинтов и генерации мира повторно не запускались. Текущие сценарии, журналы, JSON и XML включены в docs/verification-2.3.28 исходного архива.
