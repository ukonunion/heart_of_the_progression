# Проверка 2.3.8 — игровой прогон пока заблокирован средой

Изменения внесены, JAR собран. Это тестовая сборка: завершённая игровая проверка отсутствует.

## Что проверено

- Изменены ровно 7 производственных исходников по сравнению с исходным архивом 2.3.7. Остальные производственные исходники совпадают побайтово.
- javac 21.0.8+9 успешно скомпилировал 13 изменённых/проверочных файлов без загрузки новых зависимостей. Использованы уже скачанные библиотеки NeoForge 21.1.256 и совместимых модов.
- Отдельный штатный JUnit Platform Launcher выполнил все 54 существующих модульных теста: 54 успешны, 0 ошибок. Включены математические проверки ресурсов, анимаций, дерева, HUD и кривой опыта. Проверочные классы новой игровой механики только скомпилированы.
- JAR собран инкрементально: неизменённые классы сохранены из проверенной 2.3.7 после сравнения исходников, изменённые перекомпилированы Java 21. В архиве изменены 11 классов (включая вложенные), 193 совпадают побайтово. Все классы JAR имеют формат Java 21. Тестовые классы и библиотеки зависимостей не включены.
- Версия в neoforge.mods.toml и манифесте — 2.3.8. Сетевой протокол 13. Текстуры, модель, числовые дорожки анимаций и лицензии сохранены.

## Какие игровые проверки подготовлены

В реальном клиенте: переход между скинтами в одном мире и между мирами за 5 искры, отсутствие дополнительной платы 25; отмена и удаление цели без списания; нехватка искры до выбора и перед завершением; прежние 25 для обычного перехода измерения; авторизация, посадка, затемнение и возврат камеры; фактическая ёмкость Iron’s по интеллекту, расход маны настоящим заклинанием и загрузка старого сохранения. На сервере: пороги интеллекта, личные открытия, сохранение, недостаток средств и общая функция списания.

## Почему игровая проверка не завершена

Обычная сборка Gradle не может соединиться со своим локальным процессом. Отдельный прямой запуск Minecraft дошёл до загрузчика, обнаружил мод 2.3.8 и прежние зависимости, но при входе в тестовый мир Windows Java не смогла создать локальное соединение: Permission denied: connect / Unable to establish loopback connection. Отдельный сервер также остановился при создании сетевого цикла. Это ограничение среды запуска; прохождение новых игровых сценариев не подтверждено. В отчёте эти проверки отмечены BLOCKED_BY_ENVIRONMENT. Старые снимки 2.3.7 не выдаются за снимки 2.3.8.
