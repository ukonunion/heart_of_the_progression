# Текстуры меню Heart of the Progression 0.2.0

Все PNG находятся в `src/main/resources/assets/rpgprogression/textures/gui/`.

## Как изменить без пересборки мода

1. Распакуйте `heart-of-the-progression-textures-0.2.0.zip` в папку Minecraft `resourcepacks/rpgprogression-custom/`. Файл `pack.mcmeta` должен оказаться прямо внутри этой папки.
2. Редактируйте нужные PNG в `assets/rpgprogression/textures/gui/`, сохраняя имена и прозрачность.
3. Включите ресурс-пак в Minecraft и поставьте его выше других паков, меняющих эти ресурсы.
4. В игре нажмите **F3+T**, чтобы перезагрузить текстуры. Java и пересборка JAR не нужны.

Можно использовать готовую распакованную папку `heart-of-the-progression-textures-0.2.0` из поставки. Если редактируете файлы в исходниках мода, потребуется `gradlew build` и установка нового JAR.

Заготовки в подпапках `icons/attributes/`, `icons/defense/`, `icons/stats/` **прозрачные**: их позиции уже подключены в меню. Нарисуйте в них иконки — они появятся без изменения Java. Это не потерянные или отсутствующие текстуры.

Предоставленные пять файлов скопированы без изменения пикселей. Фон масштабируется целиком, модель игрока, тексты и значения рисуются поверх. Размер логической панели 640×360; базовый фон растягивается вдвое. Интерфейс целиком подстраивается под разрешение и GUI Scale, вместе с координатами мыши.

Для HD-версии допустимо увеличить размер PNG целым множителем, сохранив пропорции и расположение элементов. Для пиксельного стиля используйте ближайшего соседа. Менять надписи на фоне не нужно: переводы находятся в `assets/rpgprogression/lang/ru_ru.json` и `en_us.json`.

Позиции задаются в `client/gui/CharacterScreen.java`, загрузка PNG — в `GuiTextures.java`. В моде остаются пять атрибутов и пять типов защиты: дополнительные неработающие строки из референса не добавлялись.
