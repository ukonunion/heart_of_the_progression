# Heart of the Progression

Исходники всех **72 выпусков** Heart of the Progression, от **0.1.0** до **2.3.31**.
Актуальная версия — **2.3.31 для Minecraft 1.21.1 / NeoForge / Java 21**.
Последний выпуск для Minecraft 1.20.1 / Forge / Java 17 — **1.0.12**.

Каждая папка `versions/<версия>` — самостоятельный проект с исходным кодом, ресурсами, тестами, Gradle Wrapper, лицензиями и документацией соответствующего выпуска.

## Сборка

Для версий 2.x нужен JDK 21 и NeoForge 1.21.1. Для версий 0.x и 1.x — JDK 17 и Forge 1.20.1.
Зависимости и их версии закреплены в проекте выбранного выпуска. Для первой загрузки зависимостей нужен интернет.

```powershell
cd versions/2.3.31
.\gradlew.bat build
```

Linux/macOS: `./gradlew build`. Готовый мод появится в `build/libs`.
Смотрите README и документы TESTING выбранной версии для настроек, совместимости и результатов её проверок.

## Что опубликовано

Код, тесты, текстуры, модели, структуры, примеры конфигурации и параметры сборки сохранены побайтово из проверенных архивов выпусков. `SOURCE-MANIFEST.json` содержит SHA-256 исходных архивов и опубликованных файлов; `FILES.txt` перечисляет файлы каждой версии.

Каталоги игрового запуска, сборки, кэши, автоматически записанные логи, скриншоты и GIF не включены в эту ветку исходников. Исторические ссылки на такие материалы в документации относятся к полным локальным пакетам выпусков. Структура сохранений и пользовательские игровые миры не публикуются.

## English

This branch contains all **72 source releases** of Heart of the Progression, from 0.1.0 to **2.3.31**.
Each `versions/<version>` folder is a standalone Gradle project. Versions 2.x target **Minecraft 1.21.1 / NeoForge / Java 21**. Versions 0.x and 1.x target **Minecraft 1.20.1 / Forge / Java 17**, with **1.0.12** as the final Forge release.

Build the selected version using `./gradlew build` or `gradlew.bat build`. See its README and testing documents for the supported optional integrations. Source files and assets retain the original archive bytes, with checksums recorded in SOURCE-MANIFEST.json. Generated logs, gameplay media, caches and local game worlds are excluded. The Bonfires teleportation adaptation retains its LGPL-3.0-only license; other project code keeps its existing MIT license. Artwork retains its authors’ respective rights.
