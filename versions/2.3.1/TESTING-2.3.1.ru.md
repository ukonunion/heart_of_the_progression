# Проверка версии 2.3.1

Сборка Java 21 / NeoForge 21.1.256 / Minecraft 1.21.1 прошла. 45 модульных тестов, 55 проверок в настоящем клиенте и 7 после полного перезапуска игры — без ошибок.

Проверены ПКМ, три действия общего меню, отдельный экран перемещений, три вкладки и фильтрация измерений, смещение вкладок на 2 исходных пикселя, состояние без выбранной цели, переход к прокачке, покупка атрибута, дерево, потеря доступа при уходе. Проверены боковая камера, наличие персонажа, возврат перспективы по кнопке выхода, Esc и после телепортации. Проверены снимок без HUD и интерфейса, показ снимка посещённой точки, сохранение PNG после полного перезапуска. Выполнены настоящие переходы в том же измерении, в Нижний мир и обратно. Сохранены бесплатность переходов, личные открытия, прокачка, камера дерева, отсутствие исцеления/смены возрождения и удвоение восстановления маны рядом со скинтом.

Моды в проверке: Epic Fight 21.16.4; ParCool 3.4.3.0; Epic x ParCool 21.0.0; Iron’s 1.21.1-3.16.3; Sodium 0.6.13+mc1.21.1; Iris 1.8.12-snapshot+mc1.21.1-local. Внешний шейдерпак не выбран.

Все четыре PNG меню совпадают с предоставленными файлами побайтово. Остальные прежние изображения, модель и общие игровые классы совпадают с 2.3.0. Изменены только три прежних клиентских класса, добавлены клиентские экраны, камера и кеш снимков. JAR не содержит тесты, миры и классы зависимостей.

Полная прежняя матрица RPG/GameTests и другие версии модов не проверялись заново. Выделенный сервер для этого обновления интерфейса не запускался; общие серверные классы совпадают с проверенной 2.3.0. Приложены 14 настоящих снимков игры, не макеты.
