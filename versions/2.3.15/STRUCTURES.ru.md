# Как подготовить структуру для мода

1. Постройте её в Minecraft Java 1.21.1 с теми же модами, чьи блоки используются в постройке.
2. В креативе с командами выдайте структурный блок: `/give @s minecraft:structure_block`.
3. В режиме «Сохранение» задайте границы постройки и имя, например `rpgprogression:ruins`. Нажмите кнопку сохранения в интерфейсе.
4. Пришлите файл `saves/<мир>/generated/rpgprogression/structures/ruins.nbt` из папки игры/экземпляра Prism. Если использовали имя без пространства имён, ищите внутри generated/minecraft/structures. Можно прислать всю папку generated архивом.
5. Укажите желаемые измерения и биомы, частоту появления, положение на поверхности/под землёй, правила основания и желаемые сундуки/мобов. Скинт в шаблоне сохраняйте выключенным: тогда он появится неактивным и потребует первого ПКМ.

Шаблон .nbt входит в мод по пути src/main/resources/data/rpgprogression/structure/ruins.nbt. Для автоматической генерации добавляются определения worldgen/structure и worldgen/structure_set; для составных построек — template_pool и jigsaw-соединения. Большие постройки можно разделить на части; обычный структурный блок сохраняет до 48 блоков по каждой оси. Схему соединений настроим после получения постройки.

Проверка шаблона в тестовом мире: `/place template rpgprogression:ruins`. Автоматическое появление в существующем мире будет в новых чанках; уже построенные области мира не перезаписываются. Для добавления в существующие места можно использовать ручное размещение.

Сейчас генерация структур не добавлена: эта инструкция описывает подготовку будущих построек.

Документация NeoForge 1.21.1 о .nbt и структурных блоках: https://docs.neoforged.net/docs/1.21.1/misc/gametest/#structure-templates
Пути generated/<namespace>/structures и data/<namespace>/structure сверены с StructureTemplateManager установленной Minecraft 1.21.1.
